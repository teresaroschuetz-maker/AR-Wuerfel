Stationskarten mit QR-Code

Ausdrucken, an den Stationen auslegen, fertig. Die Kinder scannen den Code mit der Kamera-App des Tablets. Dann öffnet sich die AR-Kamera gleich mit dem richtigen Objekt.

Hinweis: Diese Seite ist gerade nicht über eine Internetadresse (https) geöffnet. Die QR-Codes funktionieren erst, wenn die Seite online ist, z. B. auf GitHub Pages.
QR-Codes werden direkt im Browser erzeugt (Bibliothek „qrcode-generator“).
